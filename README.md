My Paint Application

Name: Kent Jasper G. Palomata
Course: BS InfoTech

A desktop drawing program built with Python, Tkinter, and Pillow. It follows the requirements in the Paint Application weekly task.
Requirements completed
Brush size slider from 1 to 100
Undo for the latest freehand stroke, shape, image opening, or clear action
Filled or outlined rectangle and oval (and triangle) using the current color
Additional Triangle tool with drag preview and image saving
Clear confirmation with Yes and No options
Six quick colors: black, red, blue, green, yellow, and purple
Open and save PNG, JPG/JPEG, and BMP images
Peach-themed interface
Saved image dimensions are exactly 900 × 550, matching the canvas

How to use
Choose Brush, Eraser, Line, Rectangle, Oval, or Triangle.
Pick a custom color with Choose Color, or use one of the six quick-color buttons.
Drag on the white canvas to draw. Shape tools show a preview while dragging.
Turn on Fill shapes to fill shapes with the selected color. Turn it off for outlines.
Move the brush-size slider from 1 to 100.
Click Undo to reverse the latest drawing action.
Click Clear and confirm to clear the canvas. Choose No to keep the drawing.
Use Open to load an image and Save to export the current canvas.
